# 사진 일괄 변환기 (Windows)

DNG 등 RAW 사진을 실제로 디코딩하여 JPG·PNG·WebP로 변환합니다. 일반 이미지도 일괄 변환하고 최대 변 길이와 화질을 조절할 수 있습니다. 원본과 기존 결과 파일을 덮어쓰지 않고 이름 뒤에 번호를 붙입니다.

## 실행

1. Windows 10/11에 Python 3.12 또는 3.13 **64비트**를 설치합니다.
2. `run.bat`를 두 번 클릭합니다. 최초 실행 시 인터넷으로 의존성을 설치합니다.
3. 사진 또는 폴더를 추가하고 저장 폴더, 출력 형식, 화질을 선택합니다.
4. 최대 변 길이를 지정하거나 0으로 원본 해상도를 유지하고 **변환 시작**을 누릅니다.

폴더 추가는 바로 아래 파일만 선택합니다. 중지는 현재 파일 처리가 끝난 후 적용됩니다. 손상되거나 지원되지 않는 파일은 실패 목록에 표시되며 다음 파일을 계속 처리합니다.

### 공유 용도 선택

- **고화질 공유용 (최대 10MB、기본)**: JPG, 원본 해상도·화질 95에서 시작, 사진당 10240KB(10MiB) 이하. 2~10MB 정도의 공유 용량을 목표로 하되, 상한만 보장합니다. 단순한 사진은 2MB보다 작을 수 있고 인위적으로 파일을 키우지 않습니다. 10MiB를 넘을 때 화질을 낮추고 필요하면 해상도도 줄입니다. JPG 재압축으로 손실이 발생하며 RAW 원본을 대체하지 않습니다.
- **고화질 (용량 제한 없음)**: JPG, 원본 해상도, 화질 95. 용량 조절을 원하지 않을 때 선택합니다.
- **카카오톡 공유용 (작은 용량)**: JPG, 최대 1920px, 시작 화질 85, 사진당 1024KB 이하. 확대 감상보다 작은 전송 용량을 우선합니다.
- **작은 파일로 공유**: JPG, 최대 1280px, 시작 화질 75, 사진당 300KB 이하.
- **20MB 이하로 줄이기**: JPG, 원본 해상도에서 시작, 시작 화질 95, 사진당 20480KB 이하(20MiB). 용량을 맞추기 위해 화질과 해상도가 낮아질 수 있습니다.
- **직접 설정**: 형식·화질·최대 변 길이·사진당 목표 KB를 직접 지정합니다. 프리셋 적용 후에도 수치를 수정할 수 있습니다.

목표 KB는 총 묶음 용량이 아닌 **사진 한 장의 상한**입니다. 실제 인코딩 크기를 확인하여 화질을 낮춘 뒤 필요하면 해상도를 줄입니다. PNG는 해상도만 줄입니다. 아주 작은 목표는 실패할 수 있습니다. 카카오톡용 수치는 편의를 위한 권장값이며 서비스 공식 제한이 아닙니다. 앱 전송 방식에 따라 추가 압축될 수 있습니다.

## EXE 만들기

Windows에서 `build.bat`를 실행합니다. `dist/PhotoBatch.exe` 단일 파일이 생성됩니다. 이 파일을 전달하세요. 받는 PC에는 Python 설치가 필요 없습니다. 이 EXE는 코드 서명되지 않습니다.

## 제한

- 화질 설정은 JPG·WebP에 적용됩니다. PNG는 무손실입니다. 파일 크기가 항상 줄어드는 것은 아닙니다.
- EXIF/GPS/ICC 메타데이터는 보존하지 않습니다. 색상 관리가 필요한 인쇄 작업에는 적합하지 않습니다.
- RAW는 카메라 화이트밸런스로 현상합니다. 카메라 JPEG 미리보기와 색감이 다를 수 있습니다. 일부 카메라·DNG 변형은 LibRaw에서 지원하지 않을 수 있습니다.
- 애니메이션 및 다중 페이지 이미지는 첫 프레임/페이지만 처리합니다. JPG의 투명 영역은 흰색이 됩니다.
- 사진은 로컬에서 처리하며 업로드하지 않습니다. 파일을 순차 처리하지만 고해상도 RAW 한 장을 디코딩할 메모리는 필요합니다.

## 개발 검증

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python app.py
```

Windows 화면 실행과 EXE 배포 검증은 Windows에서 별도로 수행해야 합니다.

### 처리 시간 측정

Linux 개발 환경에서 6400×6400, 16비트 CFA 합성 DNG(81.92MB)를 JPG(20.17MB, 약 19.24MiB)로 변환하는 데 8.85초가 걸렸습니다. 시작 화질 95, 최대 해상도 제한 없음, 출력 상한 20MiB 조건으로 측정한 단일 실행입니다. 실제 카메라 DNG, Windows PC 성능, 저장장치와 사진 내용에 따라 달라지며 Windows 성능 보장은 아닙니다.

GitHub에 파일을 올린 경우 Actions의 **Build Windows EXE → Run workflow**로 Windows 빌드를 실행할 수도 있습니다. 완료 후 `PhotoBatch-Windows-x64` 아티팩트를 내려받아 압축을 풀고 실행합니다. `v*` 태그를 업로드하면 자동 빌드·EXE 자체 검증 후 GitHub Release에 `PhotoBatch.exe`를 게시합니다.
